# NetworkHomelab Static Website

A single-page static portfolio inspired by terminal/DevOps interfaces.

Files:
- index.html
- style.css
- script.js
- CV.pdf (optional; add your own)

Production:
Copy the files to `/var/www/networkhomelab/` and let Nginx serve `index.html`.

Before publishing, replace:
- GitHub links
- LinkedIn links
- email address
- CV.pdf
- project descriptions
- name/title if needed
